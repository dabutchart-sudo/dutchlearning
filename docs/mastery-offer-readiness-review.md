# Mastery offer readiness — local review

The saved `proof-ready` state previously controlled the top Course offer and first mastery start. An older or inconsistent state could retain that flag with fewer than the configured 40 practice answers. The UI would then suggest a test despite the documented practice minimum. This is a source-level failure mode; the affected learner's actual count has not been inspected.

The local correction checks the recorded practice count for an initial mastery test in both the offer and the start guard. The Course journey and topic detail show how many answers remain. A prior saved mastery attempt bypasses this initial gate, preserving the next-study-day full retake even for legacy histories. When a test is eligible, Course offers a choice between the full test and continued practice and says that availability does not predict a pass.

The owner subsequently reported that the installed V5.1.159 phone app reached the F1 choice screen but tapping **Start Mastery Test** appeared to do nothing. Source review found that start errors are sent to `#system-message`, which is hidden during a Learning session. The exact error on that phone has not been observed. The local correction shows session errors beside the action and briefly labels the button **Starting test…** while it works. It also checks compatible unseen test capacity before offering or starting the test. If capacity is exhausted, the Course action stays with practice and explains why. No saved progress is altered by these checks.

Focused tests cover an inconsistent ready flag, reaching the practice minimum, a prior failed test with an older count, and exhausted unseen F1 test material. The full 450-test local suite passes. The daily 20, test length, pass thresholds, vocabulary readiness, retention, learner data and sync are unchanged. This is a local candidate; no merge or deployment has occurred. The current V5.1.159 production app and standalone Flashcards fallback remain available. The phone start path still needs owner verification against the real synced history.
