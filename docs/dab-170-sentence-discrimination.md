# DAB-170 — sentence discrimination

Status: owner-authorised production release, V5.1.165, 3 October 2026. Optional Practice only. Installed-phone audio confirmation is still outstanding.

This is the first new listening step after hidden-text meaning selection. It is optional Practice only.

## What the learner does

On a topic that has already been taught, open the topic and choose **Which sentence did you hear?** The app plays one hidden Dutch sentence. Three written Dutch sentences appear. The learner chooses the line they heard, then Check answer.

The round contains at most five questions. Leaving it saves nothing.

## Format contract

| | |
| --- | --- |
| Capability | Listening, but only as a session diagnostic. A heard answer does not change Course, mastery, retention, or the capability profile. |
| Role | Practice. It is not a lesson step, a daily question, or a proof. |
| Prompt | Dutch audio only. The target sentence stays hidden until feedback, or until the learner says the audio is unclear or unavailable. |
| Response | Choose the matching Dutch sentence from three lines. |
| Acceptable answer | The heard sentence, ignoring capital letters and closing punctuation. The other two lines are different practice sentences from the same topic. Where a sentence with the same subject or verb exists, at least one option is that kind of near match. Proof sentences are never used. |
| Near miss | Choosing another line is simply not the heard sentence. Feedback shows the heard sentence, its English meaning, and the meaning of the line that was chosen. |
| Help | Replaying the audio is not help. There is no “show the answer” control before Check answer, because showing the target would remove the listening task. |
| Audio failure | **Audio unclear** or **Audio unavailable** reveals the Dutch sentence and asks for its English meaning. That answer is recognition, not listening, and the round continues. |
| Repeated failure | The round stays finite. A miss is explained, then the next question appears. No extra questions are added. |
| Offline or service failure | The same Dutch audio path as the rest of the app is used. If it cannot play, the meaning fallback above keeps this optional round moving. The normal daily session is separate and is not blocked. |
| Phone layout | One question card, with Check answer kept reachable at the bottom of the card. |
| Resume | The round lives only in the open page. Refreshing or leaving discards it. Nothing is written to learner history or synced. |

## What this does not change

The normal daily listening question, the 20-question day, mastery, retention, Flashcards, saved progress, and the existing audio service stay as they are.

## Still to come in DAB-170

Missing heard word, short dictation, two-line exchanges, and controlled voice or speed changes. Each of those also starts as optional Practice and needs its own acceptance before it can enter a normal study day.
